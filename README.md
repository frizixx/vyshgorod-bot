# Вишгород Бот 🤖

Telegram бот для жителів Вишгорода з актуальною інформацією про відключення електроенергії, новини, повітряні тривоги та погоду.

## ✨ Функціонал

### 🔌 Графіки відключень
- Персональний вибір групи відключень (1.1, 1.2, 1.4, 2.1, 6.2)
- Сповіщення за 30 хв до відключення
- Відображення поточного статусу (є світло чи ні)
- Розрахунок наступного відключення

### 📰 Новини
- Автоматичний парсинг з vyshgorod.in.ua кожні 30 хвилин
- Топ-5 останніх новин по запиту
- Превью та посилання на повну статтю

### 🚨 Повітряні тривоги
- Моментальні сповіщення про початок/відбій тривоги
- Перевірка статусу по запиту
- Час початку тривоги
- Фоллбеки через кілька API

### 🌤 Погода
- Щоденний ранковий прогноз о 7:00
- Температура, відчувається як, вологість, вітер
- Опис погодних умов українською
- Актуальні дані з wttr.in та OpenMeteo

### 🚌 Розклад маршруток
- Міські, приміські та районні маршрути
- Вишгород ↔ Київ, Димер, Лютіж, Катюжанка
- Посилання на актуальний розклад

### 🆘 Екстрені контакти
- Всі екстрені служби (102, 103, 101, 104, 112)
- Контакти міської ради
- ДТЕК, водоканал, теплопостачання
- Швидкий доступ у критичних ситуаціях

### 📍 Корисні посилання
- Офіційні сайти міста
- Telegram канали новин та тривог
- Графіки відключень
- Пункти незламності

### ⚙️ Налаштування
- Вибір групи відключень
- Увімкнення/вимкнення сповіщень
- Перегляд профілю користувача

## 🎯 Команди бота

### Основні команди:
- `/start` - Головне меню та клавіатура
- `/queue` - Обрати групу відключень
- `/help` - Довідка по всім командам
- `/about` - Інформація про бота та статистика

### Кнопки меню:
- `📰 Новини` - Останні 5 новин Вишгорода
- `🔌 Графік відключень` - Ваш персональний графік
- `🚨 Тривоги` - Актуальний стан повітряної тривоги
- `🌤 Погода` - Поточний прогноз погоди
- `🚌 Розклад маршруток` - Транспортні маршрути
- `🆘 Контакти` - Екстрені та важливі номери
- `📍 Корисні посилання` - Сайти та канали міста
- `⚙️ Налаштування` - Управління сповіщеннями

## 🚀 Встановлення

### Локально

```bash
# Клонувати репозиторій
git clone https://github.com/frizixx/vyshgorod-bot.git
cd vyshgorod-bot

# Встановити залежності
npm install

# Створити .env файл
cp .env.example .env
# Додати BOT_TOKEN в .env

# Запустити бота
npm start
```

### Деплой на Railway.app

```bash
# Ініціалізувати Railway проект
railway init

# Встановити BOT_TOKEN
railway variables --set BOT_TOKEN=your_token_here

# Задеплоїти
railway up
```

### Деплой на Render.com

1. Зареєструватися на [render.com](https://render.com)
2. New → Web Service → підключити GitHub
3. Додати змінну `BOT_TOKEN` в Environment
4. Deploy

### Деплой на Fly.io

```bash
# Ініціалізувати проект
fly launch

# Встановити секрет
fly secrets set BOT_TOKEN=your_token_here

# Задеплоїти
fly deploy
```

## 🛠 Технології

- **Node.js 18+**
- **node-telegram-bot-api** - Telegram Bot API
- **Cheerio** - Web scraping новин
- **node-cron** - Scheduled tasks (новини, тривоги, погода)
- **sql.js** - SQLite база даних (користувачі, підписки)
- **Axios** - HTTP запити до API

## 📊 Структура проекта

```
vyshgorod-bot/
├── index.js          # Entry point, health check server
├── bot.js            # Bot commands, handlers, всі кнопки
├── scheduler.js      # Cron jobs (новини, тривоги, погода)
├── parsers.js        # Web scraping та API calls
├── db.js             # SQLite database (users, subscriptions)
├── config.js         # Конфігурація (графіки, джерела)
├── bot.db            # База даних (SQLite)
├── package.json      # Dependencies
├── Dockerfile        # Docker image (для Fly.io)
├── render.yaml       # Render.com конфігурація
└── README.md         # Ця документація
```
